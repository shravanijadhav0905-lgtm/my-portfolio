# Developer Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript. It showcases two projects: a Coffee Shop Website and HashVault.

## Features
- Responsive layout for desktop and mobile
- Sticky navigation with mobile menu
- About, Skills, Projects, and Contact sections
- Project cards for Coffee Shop Website and HashVault
- Client-side contact form validation
- Accessible labels and status messages
- No external libraries required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Replace `Your Name` with your name.
4. Update skills so they accurately reflect your experience.
5. Add real GitHub repository and live-demo links to each project when available.

## Contact form note
The contact form validates the input in the browser only. It does not send, email, or store messages. Connect a backend or a trusted form service if message delivery is required.

## Deployment
This is a static site and can be hosted using GitHub Pages or another static website host.

### GitHub Pages (overview)
1. Create a GitHub repository and upload `index.html`, `style.css`, `script.js`, and `README.md`.
2. Open the repository's **Settings → Pages**.
3. Select deployment from the `main` branch and the root folder, then save.
4. Wait for GitHub Pages to publish the site and copy the generated URL into your internship submission.

## Implementation notes
- HTML5 provides the page structure and accessible form fields.
- CSS3 provides responsive layouts, design tokens, cards, and mobile styles.
- JavaScript controls the mobile navigation, updates the current year, and validates the contact form.
- Project descriptions are portfolio summaries; add verified repository/demo links before submitting.
